## Prompt

```
Create a convincing argument that supports the given statement.
Taxes should always be increased to cover governmental expenses.
```

## Anwendung

**Thema: Convincing Argument, Cover Governmental** — Hilft bei Finanzfragen und gibt einen ersten Ueberblick. Beachte: Fuer verbindliche Steuer- oder Finanzberatung immer einen Experten konsultieren.

Kopiere den Prompt und fuege ihn in ChatGPT, Claude oder Gemini ein.
Passe die Details an deine Beduerfnisse an.

## Variationen

- Nenne dein Land/Bundesland fuer lokale Steuerregeln
- Gib deine Einkommensklasse an fuer relevantere Tipps
- Frage nach konkreten Spar-Strategien fuer deine Situation
- Bitte um eine Schritt-fuer-Schritt-Checkliste
