## Prompt

```
Please provide a JSON data with the names of 5 famous fashion designers.
Rewritten prompt:
I need a list of 5 famous fashion designers in JSON format. Can you provide me with the required data? The JSON should have the following format:
{
  "designers": [
    {"name": "Designer 1"},
    {"name": "Designer 2"},
    {"name": "Designer 3"},
    {"name": "Designer 4"},
    {"name": "Designer 5"}
  ]
}
Please fill in the names of the designers in the JSON data format.
```

## Anwendung

**Thema: Json Data, Famous Fashion** — Ideal fuer Mode-Inspiration und Outfit-Planung. Die KI gibt dir personalisierte Styling-Tipps passend zu deinem Anlass.

Kopiere den Prompt und fuege ihn in ChatGPT, Claude oder Gemini ein.
Passe die Details an deine Beduerfnisse an.

- Nenne ein konkretes Event (Bewerbungsgespraech, Date, Hochzeit)
- Frage nach Budget-freundlichen Alternativen
- Bitte um Farb-Kombinationsvorschlaege
